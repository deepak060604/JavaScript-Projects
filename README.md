# Tic Tac Toe 🎮

A simple and interactive **Tic Tac Toe game** developed as a beginner-friendly project to practice programming logic, user interaction, and game development concepts.

## 🚀 Features

* 👥 Two-player gameplay
* ❌ Player 1 uses **X**
* ⭕ Player 2 uses **O**
* 🏆 Automatically detects the winner
* 🤝 Detects a draw when the board is full
* 🔄 Option to restart the game
* 🎨 Simple and user-friendly interface
* ⚡ Fast and lightweight

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🎯 How to Play

1. Player 1 starts with **X**.
2. Player 2 plays with **O**.
3. Players take turns selecting an empty cell.
4. The first player to get three symbols in a row — horizontally, vertically, or diagonally — wins.
5. If all cells are filled without a winner, the game ends in a draw.
6. Click **Restart** to play again.
